# 班主任新手引导

目标：让初次使用的班主任完成真实班级配置，再开始积分与考勤。采用现有蓝白界面，使用虚线定位框、浅色遮罩、连线箭头和半透明说明浮层。一次只说明当前任务，直接操作原页面；引导不替用户设置规则或修改学生积分。

## 首次设置顺序

| 步骤 | 定位位置 | 操作与依赖 |
| --- | --- | --- |
| 1 维护密码 | 维护验证 | 设置独立维护密码或解锁；沿用服务器权限验证。未解锁不能以“完成”前进，可以跳过。 |
| 2 班级信息 | 维护 → 系统配置 → 基础设置 | 班级名称、积分称呼、功能开关。附加榜单、双子星和宠物按需要开启。 |
| 3 组织架构 | 小组、宿舍、工资设置 | 自定义组名；设置宿舍或走读；确认工资金额和发放小组。模板下载、导入要求先存在小组与宿舍。预置纪律、卫生组的一些功能仍按内部编号关联。 |
| 4 学生名单 | 学生名单维护 | 下载当前配置生成的模板，核对表头与小组/宿舍名称，增量导入或手动新增。空名单、空姓名、重复姓名、失效的小组/宿舍引用不会被引导当作名单就绪；可以跳过。 |
| 5 保存确认 | 保存配置按钮 | 必须收到本次步骤期间的配置保存成功回调，才能点击“保存成功，继续”。失败使用原有错误提示，可重试。不会用“点了保存”代替服务端成功。 |
| 6 积分规则 | 积分 → 设置 | 学科、理由和分值、日常登记、专员奖励、恢复规则；仍需点击原有“打开设置”并接受维护权限检查。可以确认默认规则，无须做真实加扣分。 |
| 7 考勤作息 | 考勤 → 教师工具 → 考勤设置 | 时段、迟到、周末和奖惩；通知、留言和语录也在教师工具。需确认同步后再正式打卡。 |

最后显示“导览已结束”，按实际数据列出班级名称、组织名称、真实名单和同步状态。这个清单不宣称积分及考勤规则已人工验收，也不把点完导览当作所有配置完成。

## 全功能梳理及渐进导览

| 功能 | 初始依赖 | 引导安排 |
| --- | --- | --- |
| 仪表盘、榜单、首页布局 | 学生及积分；角色、值日、日程等是可选资料 | 日常第 1 步。空班级示例学生不算真实名单。 |
| 快速积分、一键工资、积分历史 | 学生、理由、工资小组及规则 | 日常第 2 步；首次只认识流程，不执行加分、归零或撤销。 |
| 作业、跑操、卫生、纪律登记 | 名单、日期、学科/原因、分值、可选专员 | 日常第 3 步，打开真实“日常登记”分区。 |
| 任务 | 学生、任务条件与奖励 | 日常第 4 步，不自动发布任务。 |
| 藏宝阁、背包、兑换与使用记录 | 学生积分、价格、库存、兑换/使用限制 | 日常第 5 步，不自动兑换或使用商品。 |
| 专员、自定义角色、卫生督查、值日 | 名单、小组及职务规则 | 进阶第 1 步，展开角色区。 |
| 考试档案 | 名单、考试成绩与模板 | 进阶第 2 步，由用户打开按需加载的档案。 |
| 双子星编队、赛制、成绩结算 | 名单、考试档案与赛制；写入积分要维护权限 | 进阶第 3 步；未启用时定位功能开关，不自动启用或结算。 |
| 头像、学生个人档案 | 真实学生名单 | 进阶第 4 步。 |
| 宠物及内置商城 | 名单、功能启用；成长关联积分和考勤 | 进阶第 5 步；关闭时定位功能开关，不自动开启、孵化或购买。 |
| 假期封存、测试模式、日程、倒计时、周报、简报、异常行为预警 | 按工具分别依赖名单、行为数据或日期 | 进阶第 6 步。说明测试副本退出不保留，名单导出不等同于完整服务器备份。 |
| 完整备份与恢复、管理员账号管理 | 运维/管理员权限 | 不引导普通教师操作服务器或管理员后台，不增加权限入口。 |

## 行为与可访问性

- **自动出现**：首次服务端同步结束后，仅对当前没有真实名单和积分历史、且本浏览器没有引导记录的普通用户弹出欢迎页。已有班级不会强制弹出，测试模式不自动弹出。
- **关闭/续看**：任意步骤可关闭或按 Esc；进度按账号保存在当前浏览器本地。刷新不会强制重新打开。回到维护中心的新手引导入口，可续看或从头开始，也可单独进入日常/进阶导览。此进度不跨浏览器、设备同步。
- **真实操作**：页面表单、文件选择和原有密码验证照常使用。浮层可以收起；遮罩和框线不拦截页面点击，不自动修改业务数据。
- **保护原流程**：继续使用现有权限、导入校验、乐观锁及保存；缺勤派生、积分、商城防护和后端均未改动。维护页改为传入真实学生数组，避免空班级新增时带入访客示例姓名。
- **定位**：按步骤切换真实导航和内部工作区；组织、名单、角色区按需展开。通过 DOM 变化、尺寸变化与滚动更新定位；手机使用底部浮层，控件可收起，定位随窗口尺寸调整。
- **键盘**：步骤说明使用非模态 dialog，不锁住真实表单；按钮有焦点样式和 44px 最小高度；新步骤聚焦说明，关闭时尽可能恢复原焦点。收起时保留可访问名称。应用模态框优先接收 Esc。
- **动态效果**：短暂进入动效、慢速虚线运动，遵守 `prefers-reduced-motion`。无音效，无自动翻页。
- **存储受限**：引导仍可使用，提示进度无法保存。
